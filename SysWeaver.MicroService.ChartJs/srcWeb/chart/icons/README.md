| | |
|---|---|
| **Project** | [SysWeaver.MicroService.ChartJs](../../../README.md) |
| **Kind** | Icons |

## Purpose

[`chart.css`](../chart.css) uses these icons as `mask-image`, so the theme colour shows through. The build optimises them with `SvgOpt -RemoveFill -RemoveSize` and serves them from `chart/icons/` (see [`srcWeb/`](../../README.md)).
