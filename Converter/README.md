## Purpose

Converters transform source code from one form to another at build time or at runtime. The folder itself only holds the project folders.

## Contents

| Item | Description |
|---|---|
| [`SysWeaver.Converter.Js/`](SysWeaver.Converter.Js/README.md) | Converts modern JavaScript (ES2026 syntax) to older versions (ES2017, ES2015, ES5 or a browser list) for old and embedded browsers, like Babel's preset-env; also converts the scripts and event handlers in html pages. |
