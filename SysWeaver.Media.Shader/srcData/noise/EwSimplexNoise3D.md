# EwSimplexNoise3D

Noise: 3D simplex noise by Ian McEwan / Ashima Arts (webgl-noise, MIT), zero centred, about [-1, 1].

## Signature

```glsl
float EwSimplexNoise3D(vec3 v)
```

## Parameters

| Name | Type | Description |
| :--- | :--- | :--- |
| v | vec3 | Sample position. Feature size is roughly one unit. |

## Returns

`float`, zero centred, about [-1, 1].

## Description

The well known textureless `snoise(vec3)`: the space is skewed into a tetrahedral grid, the 4
corners of the containing simplex are found with `step` comparisons, lattice coordinates are
hashed with nested [EwPermute289](EwPermute289.md) calls, and gradients are generated by mapping
a 7x7 grid onto an octahedron (no lookup table). Each corner contributes
`max(0.6 - r^2, 0)^4 * dot(gradient, offset)`, scaled by 42.

`taylorInvSqrt(r)` from the original is inlined as `1.79284291400159 - 0.85373472095314 * r`
(a first order approximation of `1 / sqrt(r)` around the typical gradient length).

Only 4 corners vs 8 for [EwValueNoise3D](EwValueNoise3D.md), isotropic, no grid artifacts, but
noticeably more arithmetic per call; for heavy volumetric loops value noise is often still
cheaper. The pattern repeats every 289 units (wrap or offset large coordinates).
Animated 2D noise: `EwSimplexNoise3D(vec3(uv * scale, iTime * speed))`.

## Requires

- [EwMod289](EwMod289.md)
- [EwPermute289](EwPermute289.md)

## Example

```glsl
float n = EwSimplexNoise3D(vec3(uv * 3.0, iTime * 0.25));
vec3 color = vec3(0.5 + 0.5 * n);
```

## Replacing local implementations

Local `snoise(vec3)` copies of webgl-noise are identical (delete `mod289`, `permute` and
`taylorInvSqrt` with it). The newer upstream version uses `0.5 - r^2` and `105.0` instead of
`0.6` / `42.0` and `+ 10.0` in `permute`; those give a slightly different pattern and contrast
but the same range. Locals returning `0.5 + 0.5 * snoise(...)` need the same remap.
