## Purpose

At run time the `iso_data/` URL folder also contains the scripts `languages.js`, `countries.js`, `currencies.js` and `phone_prefixes.js` (generated by [`IsoDataHttpServerModule`](../../IsoDataHttpServerModule.cs) and registered in the static data module) and the flag URLs `iso_data/country/…`, `iso_data/language/…` and `iso_data/phone_prefix/…`. None of these exist as files here; this folder only holds the icons sub folder.
