| | |

## Purpose

At run time the `iso_data/` URL folder also contains the scripts `languages.js`, `countries.js`, `currencies.js` and `phone_prefixes.js` (generated by [`IsoDataHttpServerModule`](../../IsoDataHttpServerModule.cs) and registered in the static data module) and the flag URLs `iso_data/country/…`, `iso_data/language/…` and `iso_data/phone_prefix/…`. None of these exist as files here; this folder only holds the icons and card template sub folders.

## Contents

| Item | Description |
|---|---|
| [`icons/`](icons/README.md) | The "unknown" fall-back icon |
| [`cards/iso.html`](cards/iso.html) | Card templates of the ISO data tables (`country`, `currency`), used by the `[TableDataCard]` attributes of `IsoCountry` and `IsoCurrency` in [SysWeaver.IsoData](../../../SysWeaver.IsoData/README.md) (`+country@iso_data/cards/iso`) |
