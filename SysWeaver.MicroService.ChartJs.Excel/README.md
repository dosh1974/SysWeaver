# SysWeaver.MicroService.ChartJs.Excel

[⬆ SysWeaver overview](../README.md)

> Chart exporters to Excel and PDF.

| | |
|---|---|
| **Layer** | Visualisation / Documents |
| **Kind** | Service (chart exporter provider) |

## Purpose

Adds Excel and PDF export to charts produced by [SysWeaver.MicroService.ChartJs](../SysWeaver.MicroService.ChartJs/README.md), built on [SysWeaver.Excel](../SysWeaver.Excel/README.md).

## Limitations and considerations

- Inherits the licensing constraints of GemBox.Spreadsheet (see [SysWeaver.Excel](../SysWeaver.Excel/README.md)).
